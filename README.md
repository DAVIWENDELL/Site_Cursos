# Site de Cursos

Site de cursos online desenvolvido com HTML, CSS, JavaScript e Bootstrap.

## O que o projeto demonstra

- Listagem e detalhes de cursos;
- Cadastro e login;
- Recuperação de acesso;
- Carrinho;
- Contato e suporte.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Como executar

Abra `index.html` em um navegador ou use um servidor local.
